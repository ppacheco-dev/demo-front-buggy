# Modelos 3D de Buggies (.glb)

Coloca aquí los archivos 3D descargados desde Scenario.gg en formato **.glb**:
- `amarillo.glb`
- `rojo.glb`
- `azul.glb`
- `verde.glb`
- `naranjo.glb`
- `morado.glb`

El visor 3D en la ficha técnica los detectará y cargará automáticamente con rotación 360°, zoom e iluminación de vitrina.
